========================================
  Navel — Checklist Publicação cPanel
========================================

PRIMÁRIO (automatizado, rápido)
-------------------------------
[ ] npm run build  (actualiza dist/; merge privacy+rgpd+patch PT → src/locales)
[ ] npm run deploy:dry  (ver o que vai ser enviado; nada escreve)
[ ] npm run deploy:all -- --yes  (envia site + PHP via FTPS incremental)

Setup prévio (uma vez): docs/DEPLOY-AUTOMATICO-CPANEL.md
Ficheiro de credenciais: .env.cpanel (gitignored, no teu PC)

FALLBACK (File Manager manual)
------------------------------
[ ] Executar OPTIMIZAR.bat (build + ZIP)
[ ] Confirmar que navel-publicar.zip foi criado

cPanel (File Manager)
---------------------
[ ] File Manager → public_html
[ ] Upload navel-publicar.zip → Extract → Apagar ZIP

DEPOIS (ambos os fluxos)
------------------------
[ ] https://navel.pt (página principal)
[ ] https://navel.pt/contacto (menu, formulário e F5 sem 404)
[ ] https://navel.pt/privacidade (PT e EN: sem chaves tipo privacy.xxx) e /rgpd e /condicoes-gerais (F5 = SPA)
[ ] https://navel.pt/sitemap.xml inclui /condicoes-gerais e /robots.txt
[ ] Formulário de contacto (email em comercial@navel.pt)
[ ] Idiomas PT, EN, ES (páginas públicas: corpo em PT quando bandeira PT; sem mistura EN no meio)
